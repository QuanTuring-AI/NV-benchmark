# prediction_p28.json (v1) — superseded, not modified

Its `stack.profile` field held the profile id followed by the display suffix that `list-model-profiles` prints (84 characters instead of the 64-hex id). `run_p28.sh` passed that value verbatim as `NIM_MODEL_PROFILE`, NIM matched neither the id nor the description, and reported "no matching profile_id or profile description is found in manifest" — every start in attempts 1–15 failed or was withheld for that reason, not for memory. v1 is kept byte for byte (sha256 in `prediction_p28.sha256`). `prediction_p28_v2.json` differs only in: `stack.profile` (bare 64-hex id), `written_at`, and the runner name `run_p28_v2.sh` in `written_before` and `harness_sha256`. `run_p28_v2.sh` refuses any profile value that is not a bare 64-hex id.
